This major update brings a practice mode, where you can keep playing as much as you want. It also adds the patch notes page, the one you are on right now :), and some minor layout changes.

<b>Changes:</b>

- Added Practice Mode: a mode where you can keep playing and guessing animals as much as you want.
- Added Patch Notes page: This is a page where you can see any updates to the game.
- Added a navigation bar to navigate all these new pages
- added a date and a count (count will only be visible tomorrow as it required some backend changes) to the daily puzzle
- Increased the vertical padding in the table.
